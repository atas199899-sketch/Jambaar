# Jambaar

Jeu d'action et de récit à la troisième personne : un jeune tirailleur sénégalais, de la Médina de Dakar (1939) à la Provence (1944). Moteur : Godot 4.3.

Voir [docs/CONCEPTION.md](docs/CONCEPTION.md) pour l'histoire, les chapitres et les points de vigilance historiques.

## État : prototype (chapitre 2 seul, en test)

**La Somme, juin 1940.** Défense de la lisière d'un village avec la section (le sergent Mamadou, Ousmane, Kouyaté, Samba et Bakary) contre trois vagues d'assaut, puis l'ordre de repli vers le camion.

## Commandes

| Action | Clavier / souris |
| --- | --- |
| Se déplacer | ZQSD / flèches, Maj pour courir |
| Épauler / tirer | clic droit / clic gauche |
| Recharger | R |
| S'accroupir (couverture) | C |
| Pansement | H |
